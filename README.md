# GradAid: Decentralized Micro-Lending Platform

## Overview

GradAid is a decentralized micro-lending platform built on the Stacks blockchain. It empowers students to request education loans, allows lenders to fund them, and facilitates secure, transparent repayment processes. This MVP focuses on core loan functionalities.

## Features

### 1. Loan Requests

Borrowers can request loans by specifying:

- Loan amount
- Interest rate
- Repayment due date.

### 2. Loan Funding

Lenders can fund loans with STX tokens, automatically transferring the funds to borrowers while storing transaction details on-chain.

### 3. Loan Repayment

Borrowers can repay loans with interest, ensuring:

- Automatic transfer of funds to the lender.
- Marking the loan as repaid.

---

## Future Implementations

GradAid's vision is to provide an innovative and comprehensive solution for decentralized education financing. Planned functionalities include:

1. **Credit Scoring Mechanism**:
   Borrowers' credit worthiness will be evaluated through a reputation system based on repayment history.

2. **Loan Portfolio Visualization**:
   Lenders will gain access to visual dashboards displaying key metrics such as repayment status, interest earned, and borrower details.

3. **Late Payment Penalties**:
   Loans will include automatic penalty calculations for overdue payments, fostering timely repayments.

4. **Community Pool Lending**:
   Lenders will be able to collaboratively fund loans via pooled systems, allowing for shared risk and diversified lending.

5. **Enhanced Security Audits**:
   Comprehensive security audits and optimizations will be implemented to protect user funds and data.
